# Raízes do Nordeste - API

API back-end da rede de restaurantes **Raízes do Nordeste**, desenvolvida para o Projeto Multidisciplinar (Trilha Back-End) da UNINTER.

## Tecnologias

- Node.js 22
- TypeScript
- Express
- Docker

## Como rodar

```bash
npm install
npm run dev
```

A API sobe em `http://localhost:3000` e a rota `GET /health` pode ser usada para conferir se está no ar.

Com Docker:

```bash
docker compose up --build
```
